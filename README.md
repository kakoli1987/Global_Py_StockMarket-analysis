# Global_Py_StockMarket-analysis
A real-time financial market analytics and AI heuristic intelligence web application built with Python and Streamlit. Designed to track global equities (US, Japan, India, UK), visualize complex financial indicators, and provide interactive trade risk management tools.

## 🚀 Key Features
* **Real-Time Market Data:** Stream live pricing feeds, market capitalization, and volume metrics via Yahoo Finance (`yfinance`).
* **Multi-Style Chart Presentations:** Toggle between Candlestick charts with Bollinger Bands and Support/Resistance lines, Clean Line trends, OHLC bars, Cumulative Area charts, and Volatility-Filtered Renko Bricks.
* **Automated Technical Indicators:** Real-time RSI calculation, dynamic support/resistance mapping, and automated trade action signals.
* **Risk Management Calculator:** Interactive modal designed to calculate stop-loss targets, take-profit levels, position sizing, and maximum risk exposure per trade.
* **Custom Watchlist & Screener:** Multi-ticker comparison tool equipped with pre-loaded blue-chip regional universes.

## 🛠️ Tech Stack
* **Framework:** Streamlit
* **Data Visualization:** Plotly
* **Data Engine:** yfinance, Pandas
* **Automation:** Streamlit-Autorefresh
